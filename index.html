AI가 늘리는 속도, 우리는 못 따라간다

  • 전사적으로 AI 도구·AI 기반 서비스 도입이 빠르게 늘고 있음 — 신규 서비스, 사내 자동화 도구, 외부 연동이 이전과 비교할 수 없는 속도로 생겨나는 중
  • 이 모든 것이 개인정보 처리 여부·보안 리스크 검토 대상이 될 수 있음
  • 모든 신규 서비스를 사람이 수작업으로 하나하나 심사하는 지금 방식은 구조적으로 지속 불가능한 지점에 도달함

05 / 18

사용자 접속 홈

포탈에 로그인하면 가장 먼저 만나는 화면입니다. 내 신청 현황을 바로 확인하고, 필요한 메뉴로 곧장 이동합니다.

  • 접수대기 / 승인 / 완료 / 실패 — 내 신청 현황을 상태 카드로 한눈에 표시
  • VPN·WAF·방화벽·악성메일 신청 이력(담당자·Jira 티켓)을 바로 확인 — 관리자는 전체 신청 큐 확인
  • 좌측 사이드바에 신청 메뉴가 상시 노출되어 클릭 한 번으로 이동
  • 정보보안 공지사항을 Slack과 함께 이 화면에도 게시할 예정 (추가 예정)

ACT 05/PRINCIPLE — 설계 원칙
13 / 18

"AI는 초안까지, 최종 판단은 반드시 사람"

AI 활용에 대한 막연한 불안(오판·과신)을 정면으로 다루는 슬라이드입니다.

AI가 자동화하는 것

  • VPN MAC 주소 등록 / 해제
  • 악성 메일 1차 스캔 및 사전 판정
  • 신청 접수 시 Jira 티켓 자동 생성

사람이 최종 결정하는 것

  • 악성 메일 최종 판정 확인
  • WAF · 방화벽 정책 예외 승인
  • VPN 자산번호-MAC 불일치 시 예외 확인

보안팀이 모르는 서비스를, 지금 함께 찾습니다

AI 활용도가 높아지며 팀 내 자체 구축 서비스의 생성 속도가 빨라지고 있습니다. 보안팀이 인지하지 못한 환경에 배포된 서비스는 접근통제·인증·로그 등 기본 보안 통제가 빠진 채 운영될 위험이 있습니다. 제출 정보는 유출 예방 목적에만 활용됩니다.
